Great conceptual question, Alex! This gets straight to the difference between contiguous physical allocation vs scattered heap references, and how modern hardware handles CPU cache locality.

1 Memory Layout: Physical Alignment

Arrays guarantee that item i+1 is parked directly next to i in RAM. Linked lists disperse nodes arbitrarily across the heap connected by 8-byte pointer chains.

2 The Hardware Level: CPU Cache Pre-fetching

memory L1/L2 Cache Prefetch Engine

When the CPU reads arr[0], the memory controller grabs an entire 64-byte Cache Line. This brings arr[1] through arr[7] directly into ultra-fast L1 cache at ~1ns latency. With linked lists, every node jump can trigger a Cache Miss, waiting 50–100ns to read raw DRAM!
